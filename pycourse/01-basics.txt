## module: py01 | Getting started with Python
summary: What programming is, how Python runs your code, your first program, comments and indentation.
=== en
### What is programming?
A program is a list of instructions for a computer. The computer is extremely fast and extremely obedient, but it has **zero common sense**. It does exactly what you write, in exactly the order you write it.

> **Analogy:** Think of a robot chef that follows a recipe word for word. If the recipe says "add salt" but not how much, the robot is stuck. If the recipe says "fry the egg" before "crack the egg", the robot tries to fry a whole egg. Programming is the skill of writing recipes that are precise, complete and in the right order.

That is also exactly what "logic building" means: breaking a task into small, exact steps.

### Why Python?
- It reads almost like English: `if age >= 18: print("adult")`.
- It has powerful built-in tools (lists, dictionaries, sets, sorting) that make DSA code short.
- It is the most popular language for coding interviews after Java and C++, and every DSA 150 solution has a Python version.

### How to run Python
You have three easy options:
1. **Online, nothing to install:** open an online Python editor such as programiz.com/python-programming/online-compiler, online-python.com or Google Colab. Type code, press Run.
2. **On your computer:** install Python 3 from python.org. Then open a terminal and type `python3` (Mac/Linux) or `python` (Windows). To run a file: save it as `hello.py` and run `python3 hello.py`.
3. **An editor like VS Code** with the Python extension. This is what you will use long term.

### Your first program
```python
print("Hello, world!")
```
`print` is a **function**: a ready-made machine that shows whatever you give it inside the round brackets. The text inside quotes is called a **string**.

Python runs your file **from top to bottom, one line at a time**:
```python
print("I wake up")
print("I brush my teeth")
print("I start coding")
```
Swap the lines and the output order changes. The computer never rearranges your steps.

### print() in more detail
```python
print("a", "b", "c")          # a b c   (separated by spaces)
print("a", "b", sep="-")      # a-b
print("no new line", end="")  # the next print continues on the same line
print(5 + 3)                  # 8  (it prints the RESULT of the expression)
print()                       # an empty line
```

### Comments
Anything after `#` on a line is a **comment**. Python ignores it. Comments are notes for humans, including future you.
```python
# This line is ignored
print("hi")  # this part is ignored too
```

### Indentation is part of the language
In most languages, spaces at the start of a line are just decoration. In Python they are **rules**. Lines that belong to the same block must start with the same number of spaces (use 4).
```python
if 5 > 3:
    print("inside the if")    # 4 spaces: belongs to the if
print("outside")              # no spaces: runs anyway
```
Wrong indentation gives an `IndentationError`.

### Errors are friends
When Python cannot understand or run your code, it prints an **error message**. Read it from the **bottom line up**: the last line says what went wrong, and the lines above say where.
```
  File "hello.py", line 1
    print("hello"
IndentationError / SyntaxError: '(' was never closed
```
Every programmer sees errors all day. The skill is reading them calmly.

> **Remember:** Type every example yourself. Change one thing, predict the output, then run it. Predicting before running is the fastest way to build logic.

## module: py02 | Variables and data types
summary: Variables as name-tags, the core types (int, float, str, bool, None), dynamic typing and type().
=== en
### A variable is a name-tag
In Python, a variable is a **name that points to a value**.
```python
age = 20
name = "Riya"
```
Read `=` as **"becomes"** or "store into", not "equals". `age = 20` means: create the value 20 and stick the name-tag `age` on it.

> **Analogy:** Values are like parcels in a warehouse. A variable is a name-tag you stick on a parcel so you can find it later. `age = 21` moves the tag to a new parcel; the old parcel is thrown away if no tag points to it.

### Reassignment
```python
score = 10
score = score + 5    # right side first: 10 + 5 = 15, then the tag moves
print(score)         # 15
```
Python always evaluates the **right side first**, then attaches the name on the left.

### Naming rules
- Letters, digits and underscores only; cannot start with a digit: `total_marks`, `x1`, `_temp` are fine; `2nd`, `my-name` are not.
- Case-sensitive: `Age` and `age` are different.
- Convention: **snake_case** (`max_sum`, `left_index`).
- Don't use names of built-ins like `list`, `str`, `sum`, `max`: you would hide the real function.

### The core data types
| Type | What it holds | Examples |
|---|---|---|
| `int` | whole numbers (any size!) | `42`, `-7`, `10**30` |
| `float` | decimal numbers | `3.14`, `-0.5`, `2.0` |
| `str` | text | `"hi"`, `'Riya'`, `""` |
| `bool` | truth values | `True`, `False` |
| `NoneType` | "nothing here" | `None` |

Check a type with `type()`:
```python
print(type(42))      # <class 'int'>
print(type(3.0))     # <class 'float'>
print(type("42"))    # <class 'str'>
```

### Dynamic typing
You never declare types in Python. The **value** has a type; the name can point to anything:
```python
x = 5        # x points to an int
x = "five"   # now x points to a str. Allowed (but confusing, so avoid it).
```

### Python ints never overflow
In C++ or Java, an `int` stops at about 2 billion. Python ints grow as big as needed: `2 ** 100` just works. This makes many problems easier, but remember that other languages don't have this.

### Floats are approximate
```python
print(0.1 + 0.2)   # 0.30000000000000004
```
Decimals are stored in binary and cannot all be exact, like 1/3 = 0.333… in decimal. Never compare floats with `==` for money-like logic; round or use integers (e.g. store paise instead of rupees).

### Multiple assignment and swapping
```python
a, b = 5, 9
a, b = b, a        # swap in one line!
print(a, b)        # 9 5
```
In most languages you need a temporary variable to swap. Python evaluates the right side (9, 5) completely first, then assigns.

### None
`None` means "no value yet" or "nothing". A function that doesn't return anything returns `None`. In DSA, `None` marks the end of a linked list or a missing child in a tree. Check it with `is None`.

> **Mistake:** `x == None` works but `x is None` is the correct style.

## module: py03 | Input, output and type conversion
summary: Reading input, converting between types, and formatting output with f-strings.
=== en
### input() always gives a string
```python
name = input("Your name: ")
print("Hi", name)
```
`input()` pauses the program, waits for the user to type and press Enter, and returns what they typed **as a string**, even if they typed digits.
```python
age = input("Age: ")     # user types 20
print(age + 1)           # TypeError! "20" + 1 makes no sense
```

### Converting types
| Function | Converts to | Example |
|---|---|---|
| `int(x)` | whole number | `int("42")` → 42, `int(7.9)` → 7 (cuts decimals) |
| `float(x)` | decimal | `float("3.5")` → 3.5 |
| `str(x)` | text | `str(42)` → "42" |
| `bool(x)` | True/False | `bool(0)` → False, `bool("hi")` → True |

```python
age = int(input("Age: "))
print(age + 1)           # works now
```
`int("abc")` raises a `ValueError`: the text is not a number.

> **Analogy:** `input()` hands you a sealed envelope with writing on it. `int()` opens the envelope and turns the writing "20" into the actual number 20 that you can do maths with.

### Reading several numbers on one line
Competitive programming and many practice sites give input like `3 5 7` on one line:
```python
a, b, c = map(int, input().split())
nums = list(map(int, input().split()))
```
`split()` breaks the text at spaces into a list of strings; `map(int, …)` converts each one.

### Formatting output with f-strings
Put `f` before the quotes and variables inside `{}`:
```python
name, marks = "Riya", 92.456
print(f"{name} scored {marks}")          # Riya scored 92.456
print(f"{name} scored {marks:.1f}")      # Riya scored 92.5
print(f"Next year: {2024 + 1}")          # expressions work too
print(f"{7:3d}|{42:<5}|")                # width/alignment: '  7|42   |'
```
f-strings are the modern, readable way. You may also see `"Hi " + name` (concatenation) or `"{} {}".format(a, b)`.

### Concatenation needs strings
```python
print("Score: " + str(90))   # must convert the number
print("Score:", 90)          # or let print add a space
```

> **Tip:** On LeetCode/DSA 150 you never call `input()`. The platform calls your function with arguments. `input()` matters for your own practice programs and competitive programming.

## module: py04 | Operators
summary: Arithmetic (/, //, %, **), comparisons, logical operators, precedence and short-circuiting.
=== en
### Arithmetic operators
| Operator | Meaning | Example | Result |
|---|---|---|---|
| `+` `-` `*` | add, subtract, multiply | `7 * 3` | 21 |
| `/` | true division (always float) | `7 / 2` | 3.5 |
| `//` | floor division (quotient) | `7 // 2` | 3 |
| `%` | remainder (modulo) | `7 % 2` | 1 |
| `**` | power | `2 ** 10` | 1024 |

`//` and `%` are the stars of DSA (Video 1): `n % 10` gives the last digit, `n // 10` removes it, `n % 2` tells even or odd.

> **Mistake:** `/` always returns a float, even for `8 / 2` (4.0). Use `//` when you need an integer index, for example `mid = (lo + hi) // 2`.

### Negative numbers with // and %
Python's `//` rounds **down** (towards minus infinity), and `%` takes the sign of the divisor:
```python
print(-7 // 2)   # -4, not -3
print(-7 % 2)    # 1
```
Most problems use non-negative numbers, but remember this when they don't.

### Assignment shortcuts
```python
x = 10
x += 5    # x = x + 5  → 15
x -= 3    # 12
x *= 2    # 24
x //= 5   # 4
```
Python has **no** `x++`. Write `x += 1`.

### Comparisons give booleans
`==` (equal), `!=` (not equal), `<`, `>`, `<=`, `>=`.
```python
print(5 == 5.0)      # True
print("a" < "b")     # True (strings compare alphabetically)
print(1 < 3 < 5)     # True: chained comparison, reads like maths
```
> **Mistake:** `=` stores, `==` asks. Writing `if x = 5:` is a SyntaxError.

### Logical operators: and, or, not
- `a and b` is True only if both are True.
- `a or b` is True if at least one is True.
- `not a` flips it.

**Short-circuit:** `and` stops at the first False; `or` stops at the first True. We use this to stay safe:
```python
if i < len(nums) and nums[i] == 0:   # nums[i] is only read when i is valid
    ...
```

### Membership and identity
- `x in collection` → is x inside? (`3 in [1, 2, 3]` → True, `"ab" in "cab"` → True)
- `a is b` → are they the same object? Use it for `None`: `if node is None`.

### Precedence (who goes first)
1. `**`
2. unary minus `-x`
3. `*` `/` `//` `%`
4. `+` `-`
5. comparisons `<` `==` `in` …
6. `not`, then `and`, then `or`

When in doubt, **add brackets**. `(lo + hi) // 2` is not the same as `lo + hi // 2`.

### Bitwise operators (preview)
`&` AND, `|` OR, `^` XOR, `~` NOT, `<<` shift left, `>>` shift right. They work on the binary form (Video 1, Level 7) and power the Bit Manipulation topic.

Python ka `//` hamesha **neeche ki taraf** round karta hai: `-7 // 2` = -4 (na ki -3), aur `-7 % 2` = 1. Zyada problems mein positive numbers hote hain, bas ye yaad rakhna.

### Shortcuts
`x += 5` matlab `x = x + 5`. Waise hi `-=`, `*=`, `//=`. Python mein `x++` **nahi hota**, `x += 1` likho.

### Comparisons ka result bool hota hai
`==` (barabar), `!=` (barabar nahi), `<`, `>`, `<=`, `>=`. `1 < 3 < 5` jaisa chained comparison bhi chalta hai, bilkul maths jaisa.

> **Galti:** `=` store karta hai, `==` poochta hai. `if x = 5:` SyntaxError dega.

### Logical operators: and, or, not
- `a and b` tabhi True jab dono True.
- `a or b` True agar koi ek bhi True.
- `not a` ulta kar deta hai.

**Short-circuit:** `and` pehle False pe ruk jata hai; `or` pehle True pe. Safety ke liye use karte hain: `if i < len(nums) and nums[i] == 0:` — index valid ho tabhi `nums[i]` padha jayega.

### in aur is
- `x in collection` → kya x andar hai? (`3 in [1, 2, 3]` → True)
- `a is b` → kya dono same object hain? `None` check ke liye: `if node is None`.

### Kaun pehle chalega (precedence)
`**` → `*` `/` `//` `%` → `+` `-` → comparisons → `not` → `and` → `or`. Shak ho toh **brackets lagao**. `(lo + hi) // 2` aur `lo + hi // 2` alag cheezein hain.

### Bitwise operators (jhalak)
`&` `|` `^` `~` `<<` `>>` binary form pe kaam karte hain (Video 1, Level 7). Bit Manipulation topic mein kaam aayenge.

## module: py05 | Conditions: if, elif, else
summary: Making decisions, elif ladders, nested conditions, truthiness and the one-line conditional.
=== en
### if is a fork in the road
```python
temp = 35
if temp > 30:
    print("Turn on the fan")
else:
    print("Enjoy the weather")
```
The condition after `if` must be something that is true or false. A colon `:` ends the line, and the block underneath is **indented**. Exactly one of the two blocks runs.

> **Analogy:** A traffic signal. Green → go. Otherwise → stop. The car never does both.

### elif: more than two paths
```python
marks = 72
if marks >= 90:
    grade = "A"
elif marks >= 75:
    grade = "B"
elif marks >= 50:
    grade = "C"
else:
    grade = "Fail"
```
Python checks from **top to bottom** and stops at the **first** true condition. That's why the `elif marks >= 75` check doesn't need `and marks < 90`: if we reached it, the first check already failed.

> **Think:** The order of checks is logic. In FizzBuzz, checking "divisible by 3" before "divisible by 15" gives the wrong answer for 15. Put the most specific rule first.

### Nested conditions
```python
if age >= 18:
    if has_ticket:
        print("Enter")
    else:
        print("Buy a ticket")
else:
    print("Too young")
```
Often you can flatten nesting with `and`: `if age >= 18 and has_ticket:`.

### Truthiness: what counts as False
These are treated as **False** in a condition: `False`, `0`, `0.0`, `""` (empty string), `[]`, `{}`, `set()`, `None`. Everything else is True.
```python
nums = []
if not nums:
    print("empty list")     # this runs
```
This is very common in Python DSA code: `while stack:` means "while the stack is not empty".

### One-line conditional (ternary)
```python
kind = "even" if n % 2 == 0 else "odd"
```
Read it as: value-if-true **if** condition **else** value-if-false.

### match-case (Python 3.10+)
```python
match command:
    case "start":
        print("Starting")
    case "stop" | "quit":
        print("Stopping")
    case _:
        print("Unknown")
```
`_` is the default. Nice for menus, but `if/elif` is enough for DSA.

### How to think about a decision problem (leap year)
Rule: divisible by 4 → leap, except divisible by 100 → not leap, unless divisible by 400 → leap.
1. **Examples by hand:** 2024 leap, 2023 not, 1900 not, 2000 leap.
2. **Order the checks:** most specific first: 400, then 100, then 4.
3. **Code:**
```python
def is_leap(y):
    if y % 400 == 0:
        return True
    if y % 100 == 0:
        return False
    return y % 4 == 0
```
4. **Test** with your hand examples. 1900: not ÷400, is ÷100 → False ✓.
