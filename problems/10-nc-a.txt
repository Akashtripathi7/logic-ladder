## topic: arrays-hashing | Arrays & Hashing

### contains-duplicate
title: Contains Duplicate
lc: 217 contains-duplicate
diff: Easy
pattern: Hash Set
problem: Return True if any value appears at least twice in the list, otherwise False.
example: [1, 2, 3, 1] → True;   [1, 2, 3, 4] → False
analogy: A bouncer at a party with a guest register: before letting someone in, he checks the register. If the name is already there, that's a duplicate.
ask:
- Empty list? → False.
- May I reorder the list? Yes (that allows the sorting idea).
hints:
- Brute force: compare every pair (i, j > i): the handshake loop from Video 1.
- If you sort, duplicates sit next to each other; compare neighbours.
- Best: walk once and remember what you've seen. Which structure answers "seen before?" in O(1)? A set.
brute: Nested loops comparing nums[i] with nums[j] for every pair.
brutecx: O(n²) time · O(1) space
signal: "Seen this before?" / "any duplicate?" → **hash set**.
optimal:
- seen = set().
- For x: if x in seen → True; else add x.
- Loop ends → False.
cx: O(n) time · O(n) space
code:
def contains_duplicate(nums):
    seen = set()
    for x in nums:
        if x in seen:
            return True
        seen.add(x)
    return False
test:
check(contains_duplicate([1, 2, 3, 1]), True)
check(contains_duplicate([1, 2, 3, 4]), False)
check(contains_duplicate([]), False)
trace:
x | seen before? | seen after
1 | no | {1}
2 | no | {1, 2}
3 | no | {1, 2, 3}
1 | YES | return True
mistakes:
- Using a list for `seen`: `x in list` is O(n), so the whole thing becomes O(n²).
hinglish:
## Sawaal
List mein koi value do baar aayi hai kya? Haan → True.
## Analogy
Party ka bouncer guest register ke saath: kisi ko andar jaane se pehle register check karta hai. Naam pehle se likha hai → duplicate.
## Kaise sochein
- Brute force: har pair compare (handshake loop) → O(n²).
- Sort karo toh duplicates pados mein aa jaate hain → O(n log n).
- Best: ek baar chalo aur jo dekha uska record rakho. "Pehle dekha?" O(1) mein kaun batata hai? **Set**.
## Pattern pehchano
"Seen before / duplicate" → hash set.
## Best approach
`seen` set; har x: pehle se hai → True, warna add. O(n) time, O(n) space.
## Galtiyan
`seen` ko list banana (lookup O(n) ho jaata hai).

### valid-anagram
title: Valid Anagram
lc: 242 valid-anagram
diff: Easy
pattern: Counting (Counter / 26-slot list)
problem: Return True if t uses exactly the same letters as s, the same number of times.
example: s = "anagram", t = "nagaram" → True;   s = "rat", t = "car" → False
analogy: Two bags of Scrabble tiles: they're anagrams if, after counting tiles letter by letter, both bags have identical counts.
ask:
- Different lengths → immediately False.
hints:
- Sorting both gives the same string if they're anagrams: O(n log n).
- Count letters instead: +1 for s, −1 for t.
- All counts zero at the end → anagram.
brute: `sorted(s) == sorted(t)`.
brutecx: O(n log n)
signal: "Same characters, different order" → **frequency count**.
optimal:
- If lengths differ → False.
- count[26]: count[s[i]] += 1, count[t[i]] −= 1.
- All zero → True. (Or `Counter(s) == Counter(t)`.)
cx: O(n) time · O(1) space
code:
def is_anagram(s, t):
    if len(s) != len(t):
        return False
    count = [0] * 26
    for a, b in zip(s, t):
        count[ord(a) - ord("a")] += 1
        count[ord(b) - ord("a")] -= 1
    return all(c == 0 for c in count)
test:
check(is_anagram("anagram", "nagaram"), True)
check(is_anagram("rat", "car"), False)
check(is_anagram("ab", "a"), False)
mistakes:
- Only checking that every letter of s is somewhere in t.
hinglish:
## Sawaal
t mein bilkul wahi letters, utni hi baar, jitne s mein hain?
## Analogy
Scrabble tiles ke do thaile: letter-by-letter ginti karke dono ke counts bilkul same hon toh anagram.
## Kaise sochein
- Length alag → False.
- Sort karke compare: O(n log n).
- Better: s ke letter pe +1, t ke letter pe −1; end mein sab 0?
## Pattern pehchano
"Same letters, alag order" → counting.
## Best approach
26 slots ki list ya `Counter(s) == Counter(t)`. O(n).

### two-sum
title: Two Sum
lc: 1 two-sum
diff: Easy
pattern: Hash Map (complement lookup)
problem: Return the indexes of the two numbers that add up to target. Exactly one answer exists; you can't use the same element twice.
example: nums = [2, 7, 11, 15], target = 9 → [0, 1]
analogy: You have ₹9 to spend on exactly two items. Walking through the shop, for each item you ask: "have I already seen an item that costs exactly what's left?" A notebook of prices you've seen answers instantly.
ask:
- Sorted? No (if it were, two pointers work: Two Sum II).
- Return values or indexes? Indexes.
hints:
- Brute force: try every pair.
- For a number x you need exactly one partner: target − x. Call it `need`.
- The question becomes "have I seen `need` already?" → a dict lookup.
- Store value → index, because the answer wants positions.
brute: Nested loops over all pairs i < j.
brutecx: O(n²) time · O(1) space
signal: "Two items that combine to a target" + unsorted → **dict of seen values**.
optimal:
- seen = {} (value → index).
- For i, x: need = target − x; if need in seen → [seen[need], i].
- Else seen[x] = i.
cx: O(n) time · O(n) space
code:
def two_sum(nums, target):
    seen = {}
    for i, x in enumerate(nums):
        need = target - x
        if need in seen:
            return [seen[need], i]
        seen[x] = i
    return []
test:
check(two_sum([2, 7, 11, 15], 9), [0, 1])
check(two_sum([3, 2, 4], 6), [1, 2])
check(two_sum([3, 3], 6), [0, 1])
trace:
i | x | need | seen | action
0 | 3 | 3 | {} | store 3→0
1 | 2 | 4 | {3:0} | store 2→1
2 | 4 | 2 | {3:0, 2:1} | 2 found → [1, 2]
mistakes:
- Storing everything first, then looking up: with [3, 3] you might pair 3 with itself. Check first, store after.
hinglish:
## Sawaal
Do numbers ke index do jinka jod target ho. Ek hi answer hai, same element do baar nahi.
## Analogy
Tumhare paas ₹9 hain aur exactly do cheezein leni hain. Dukaan mein chalte hue har item pe socho: "kya maine pehle koi aisa item dekha jiska price bilkul baaki bache paise jitna ho?" Dekhe hue prices ki notebook turant batati hai.
## Kaise sochein
- Brute force: har pair try karo, O(n²).
- Har x ko bas ek partner chahiye: `need = target − x`.
- Sawaal ban gaya: "`need` pehle dekha?" → dict lookup.
- Index chahiye, isliye value → index store karo.
## Pattern pehchano
"Do cheezein jo milke target banayein" + unsorted → dict of seen values.
## Best approach
Ek pass: pehle `need` check, phir current store. O(n).
## Galtiyan
Pehle sab store karke phir dhoondhna ([3, 3] mein 3 khud se pair ho sakta hai).

### group-anagrams
title: Group Anagrams
lc: 49 group-anagrams
diff: Medium
pattern: Dict with a computed key
problem: Group words that are anagrams of each other.
example: ["eat","tea","tan","ate","nat","bat"] → [["eat","tea","ate"], ["tan","nat"], ["bat"]]
analogy: Sorting letters into post-office boxes by PIN code. Every anagram has the same "PIN code": its letters in sorted order. Words with the same code go in the same box.
hints:
- Anagrams share a "signature". What could it be?
- Sorted letters: "eat" → "aet", "tea" → "aet". Same key!
- dict key → list of words. Every word goes into its key's bucket.
- Faster key: a tuple of the 26 letter counts.
brute: For each word, compare it with every existing group using an anagram check.
brutecx: O(n²·k)
signal: "Group equivalent things" → **dict from a canonical key to a list**.
optimal:
- groups = defaultdict(list).
- For w: groups["".join(sorted(w))].append(w).
- Return list(groups.values()).
cx: O(n·k log k) (k = word length) · O(n·k) space
code:
from collections import defaultdict

def group_anagrams(words):
    groups = defaultdict(list)
    for w in words:
        groups["".join(sorted(w))].append(w)
    return list(groups.values())
test:
check_u(group_anagrams(["eat", "tea", "tan", "ate", "nat", "bat"]), [["eat", "tea", "ate"], ["tan", "nat"], ["bat"]])
check_u(group_anagrams([""]), [[""]])
trace:
word | key | groups
eat | aet | {aet: [eat]}
tea | aet | {aet: [eat, tea]}
tan | ant | {…, ant: [tan]}
ate | aet | {aet: [eat, tea, ate], …}
nat | ant | {ant: [tan, nat]}
bat | abt | {…, abt: [bat]}
mistakes:
- Using a list as a dict key: lists aren't hashable. Use a string or a tuple.
hinglish:
## Sawaal
Jo words ek doosre ke anagram hain unhe ek group mein rakho.
## Analogy
Post office mein letters ko PIN code ke hisaab se boxes mein daalna. Har anagram ka "PIN code" same hai: uske letters sorted order mein. Same code → same box.
## Kaise sochein
- Anagrams ka ek common "signature" hota hai. Kya?
- Sorted letters: "eat" → "aet", "tea" → "aet".
- Dict: key → words ki list.
## Pattern pehchano
"Equivalent cheezein group karo" → canonical key wala dict.
## Best approach
`defaultdict(list)`, key = `"".join(sorted(w))`. O(n·k log k).
## Galtiyan
List ko dict key banana (hashable nahi hai).

### top-k-frequent-elements
title: Top K Frequent Elements
lc: 347 top-k-frequent-elements
diff: Medium
pattern: Counting + bucket sort
problem: Return the k most frequent values (the answer is unique; any order).
example: nums = [1, 1, 1, 2, 2, 3], k = 2 → [1, 2]
analogy: Election results: first count the votes, then line the candidates up in rows by vote count (row 3 votes, row 2 votes…), and read from the busiest row down until you have k winners.
hints:
- Step 1 is clear: count with a dict/Counter.
- Then you need the k largest counts. Sorting is O(n log n).
- A count is at most n. Buckets 0..n where bucket[c] holds values with count c.
- Walk buckets from high to low until you have k values.
brute: Count, sort by count descending, take k (`Counter.most_common(k)`).
brutecx: O(n log n)
signal: "Top k by frequency" → count, then **bucket by frequency** (O(n)) or a heap (O(n log k)).
optimal:
- count = Counter(nums). buckets = [[] for _ in range(n + 1)].
- For value, c: buckets[c].append(value).
- From c = n down to 1: collect until k values.
cx: O(n) time · O(n) space
code:
from collections import Counter

def top_k_frequent(nums, k):
    count = Counter(nums)
    buckets = [[] for _ in range(len(nums) + 1)]
    for value, c in count.items():
        buckets[c].append(value)
    result = []
    for c in range(len(nums), 0, -1):
        for v in buckets[c]:
            result.append(v)
            if len(result) == k:
                return result
    return result
test:
check_u(top_k_frequent([1, 1, 1, 2, 2, 3], 2), [1, 2])
check_u(top_k_frequent([1], 1), [1])
trace:
step | state
count | {1: 3, 2: 2, 3: 1}
buckets | [[], [3], [2], [1], [], [], []]
c = 3 | take 1
c = 2 | take 2 → done
mistakes:
- Making n buckets instead of n + 1 (a value can appear n times).
hinglish:
## Sawaal
Sabse zyada baar aane wale k values do.
## Analogy
Election result: pehle votes gino, phir candidates ko vote-count ki rows mein khada karo (3 vote wali row, 2 vote wali…), aur sabse bhari row se neeche padhte jao jab tak k winners na mil jaayein.
## Kaise sochein
- Pehle Counter se ginti.
- Top k counts chahiye; sort karna O(n log n).
- Count max n ho sakta hai → buckets 0..n, `bucket[c]` mein count c wale values.
- Upar se neeche buckets padho.
## Pattern pehchano
"Top k by frequency" → bucket sort (O(n)) ya heap.
## Best approach
Counter + buckets, O(n).

### encode-and-decode-strings
title: Encode and Decode Strings
lc: 271 encode-and-decode-strings
nc: string-encode-and-decode
diff: Medium
pattern: Length-prefix encoding
problem: Design encode(list of strings) → one string, and decode(string) → the original list. The strings can contain ANY character.
example: ["good", "code", "love", "you"] → "4#good4#code4#love3#you" → back to the list
analogy: Packing parcels into one truck: on each parcel you write its weight on the outside. The receiver reads the label, unloads exactly that much, and never has to open a parcel to know where it ends.
ask:
- Can strings contain "#" or ","? Yes, anything, so a plain separator breaks.
hints:
- Joining with "," fails when a word contains ",".
- Put the LENGTH in front of each word, then a marker: "4#good".
- To decode: read digits up to "#", then take exactly that many characters. You never look inside the content.
brute: Join with a special delimiter: breaks when the delimiter appears in the data.
brutecx: O(n) but incorrect in general
signal: Serialising data that can contain anything → **length prefix**.
optimal:
- encode: "".join(f"{len(s)}#{s}" for s in strs).
- decode: i = 0; j = i; move j to '#'; length = int(s[i:j]); word = s[j + 1 : j + 1 + length]; i = j + 1 + length.
cx: O(total characters) time and space
code:
def encode(strs):
    return "".join(f"{len(s)}#{s}" for s in strs)

def decode(s):
    out, i = [], 0
    while i < len(s):
        j = i
        while s[j] != "#":
            j += 1
        length = int(s[i:j])
        out.append(s[j + 1 : j + 1 + length])
        i = j + 1 + length
    return out
test:
check(decode(encode(["good", "code", "love", "you"])), ["good", "code", "love", "you"])
check(decode(encode(["a#b", "", "12#"])), ["a#b", "", "12#"])
check(decode(encode([])), [])
trace:
i | j at '#' | length | word
0 | 1 | 4 | good
6 | 7 | 4 | code
12 | 13 | 4 | love
18 | 19 | 3 | you
mistakes:
- Searching for '#' from the start of the whole string instead of from i.
hinglish:
## Sawaal
Strings ki list ko ek string mein encode karo aur wapas decode karo. Strings mein koi bhi character ho sakta hai.
## Analogy
Ek truck mein parcels bharna: har parcel ke bahar uska weight likh do. Receiver label padhta hai, bilkul utna hi utaarta hai, parcel kholne ki zaroorat nahi padti.
## Kaise sochein
- "," se jodna fail hoga agar word mein "," ho.
- Har word ke aage uski LENGTH aur "#": "4#good".
- Decode: "#" tak digits padho, phir exactly utne characters lo. Andar ka content kabhi check nahi karna padta.
## Pattern pehchano
Kuch bhi contain kar sakne wala data serialize karna → length prefix.
## Best approach
O(total characters).

### product-of-array-except-self
title: Product of Array Except Self
lc: 238 product-of-array-except-self
diff: Medium
pattern: Prefix & suffix products
problem: Return a list where answer[i] is the product of all numbers except nums[i], without division, in O(n).
example: [1, 2, 3, 4] → [24, 12, 8, 6]
analogy: A relay team photo where each runner wants to know the combined "strength" of everyone else: multiply everyone standing to their left, then everyone to their right.
ask:
- Why no division? Zeros would break it, and it's forbidden.
hints:
- Brute force: for each i, multiply all the others: O(n²).
- answer[i] = (product of everything LEFT of i) × (product of everything RIGHT of i).
- Left products build in one pass from the left; right products in one pass from the right, like prefix sums.
- Store left products in the answer, then multiply in right products with one running variable.
brute: For each i, loop over all j != i.
brutecx: O(n²)
signal: "Combine everything except myself" → **prefix and suffix** passes.
optimal:
- ans[0] = 1; ans[i] = ans[i − 1] × nums[i − 1].
- right = 1; for i from n − 1 down: ans[i] *= right; right *= nums[i].
cx: O(n) time · O(1) extra space
code:
def product_except_self(nums):
    n = len(nums)
    ans = [1] * n
    for i in range(1, n):
        ans[i] = ans[i - 1] * nums[i - 1]
    right = 1
    for i in range(n - 1, -1, -1):
        ans[i] *= right
        right *= nums[i]
    return ans
test:
check(product_except_self([1, 2, 3, 4]), [24, 12, 8, 6])
check(product_except_self([-1, 1, 0, -3, 3]), [0, 0, 9, 0, 0])
trace:
i | left product | right product | answer
0 | 1 | 24 | 24
1 | 1 | 12 | 12
2 | 2 | 4 | 8
3 | 6 | 1 | 6
mistakes:
- Updating `right *= nums[i]` before `ans[i] *= right` (includes nums[i] itself).
hinglish:
## Sawaal
Har position ke liye baaki sab numbers ka product, bina division ke, O(n) mein.
## Analogy
Relay team ki photo mein har runner jaanna chahta hai baaki sabki combined "strength": uske left wale sab ka product × right wale sab ka product.
## Kaise sochein
- Brute force har i ke liye baaki sab multiply: O(n²).
- answer[i] = (left ka product) × (right ka product).
- Left products ek pass mein, right products ulte pass mein (prefix sums jaisa).
## Pattern pehchano
"Mere alawa sab" → prefix + suffix.
## Best approach
Answer list mein left products, phir ek `right` variable se right products multiply. O(n), O(1) extra.
## Galtiyan
`right *= nums[i]` pehle kar dena.

### valid-sudoku
title: Valid Sudoku
lc: 36 valid-sudoku
diff: Medium
pattern: Sets per row / column / box
problem: Check whether a partly filled 9×9 board breaks any Sudoku rule: no repeated digit in any row, column or 3×3 box. Empty cells are ".".
example: A board with two 8s in the top-left box → False
analogy: Three kinds of hostel registers (one per floor, one per wing, one per block). Before a student checks into a room, all three registers are checked for their name.
hints:
- You need 27 "seen" sets: 9 rows, 9 columns, 9 boxes.
- For cell (r, c), which box? (r // 3, c // 3), or the number (r // 3) * 3 + c // 3.
- One pass over the 81 cells; a digit already seen in its row, column or box → False.
brute: Check each row, each column and each box separately. Also fine: O(81).
brutecx: O(81) = O(1)
signal: "No repeats within groups" → **one set per group**; compute the group index with //.
optimal:
- rows, cols, boxes = defaultdict(set) each.
- For each filled cell: if d in rows[r] or cols[c] or boxes[(r//3, c//3)] → False; else add.
cx: O(81) time and space
code:
from collections import defaultdict

def is_valid_sudoku(board):
    rows, cols, boxes = defaultdict(set), defaultdict(set), defaultdict(set)
    for r in range(9):
        for c in range(9):
            d = board[r][c]
            if d == ".":
                continue
            b = (r // 3, c // 3)
            if d in rows[r] or d in cols[c] or d in boxes[b]:
                return False
            rows[r].add(d)
            cols[c].add(d)
            boxes[b].add(d)
    return True
test:
board = [list(r) for r in ["53..7....", "6..195...", ".98....6.", "8...6...3", "4..8.3..1", "7...2...6", ".6....28.", "...419..5", "....8..79"]]
check(is_valid_sudoku(board), True)
board[0][0] = "8"
check(is_valid_sudoku(board), False)
mistakes:
- Getting the box formula wrong: test it on (4, 7) → (1, 2).
hinglish:
## Sawaal
Aadhe bhare Sudoku board mein koi rule toot raha hai? Row, column ya 3×3 box mein koi digit repeat nahi hona chahiye.
## Analogy
Hostel ke teen tarah ke register (har floor, har wing, har block ka). Student ke room lene se pehle teeno registers mein naam check hota hai.
## Kaise sochein
- 27 sets: 9 rows, 9 columns, 9 boxes.
- Cell (r, c) ka box: `(r // 3, c // 3)`.
- Ek pass mein har digit check karo, pehle dekha hua mile → False.
## Pattern pehchano
"Groups ke andar repeat nahi" → har group ka set.
## Best approach
O(81) = constant.

### longest-consecutive-sequence
title: Longest Consecutive Sequence
lc: 128 longest-consecutive-sequence
diff: Medium
pattern: Set + "start of a run"
problem: Return the length of the longest run of consecutive integers that can be formed from an unsorted list, in O(n).
example: [100, 4, 200, 1, 3, 2] → 4   (1, 2, 3, 4)
analogy: Finding the longest chain of consecutive house numbers on a street: only start counting from a house whose previous number doesn't exist (the start of a block), then walk forward.
hints:
- Sorting then counting runs is O(n log n); we need O(n).
- Put everything in a set so "is x + 1 here?" is O(1).
- Start counting only from numbers that begin a run: x − 1 is NOT in the set.
- From each start, count up while x + 1, x + 2 … exist. Each number is visited at most twice.
brute: Sort, then walk counting consecutive steps (skipping duplicates).
brutecx: O(n log n)
signal: "Consecutive values in unsorted data, O(n)" → **set + only expand from a run's start**.
optimal:
- s = set(nums); best = 0.
- For x in s: if x − 1 not in s: length = 1; while x + length in s: length += 1; best = max(best, length).
cx: O(n) time · O(n) space
code:
def longest_consecutive(nums):
    s = set(nums)
    best = 0
    for x in s:
        if x - 1 not in s:
            length = 1
            while x + length in s:
                length += 1
            best = max(best, length)
    return best
test:
check(longest_consecutive([100, 4, 200, 1, 3, 2]), 4)
check(longest_consecutive([0, 3, 7, 2, 5, 8, 4, 6, 0, 1]), 9)
check(longest_consecutive([]), 0)
trace:
x | x−1 in set? | start? | run length
100 | no | yes | 1
4 | yes | no | —
200 | no | yes | 1
1 | no | yes | 1→2→3→4
3 | yes | no | —
2 | yes | no | —
mistakes:
- Expanding from every number (not just starts), which becomes O(n²).
hinglish:
## Sawaal
Unsorted list se banne wali lagatar integers ki sabse lambi chain ki length, O(n) mein.
## Analogy
Gali mein lagatar house numbers ki sabse lambi chain: ginti sirf us ghar se shuru karo jiska pichhla number exist nahi karta (block ki shuruaat), phir aage chalo.
## Kaise sochein
- Sort karke O(n log n); humein O(n) chahiye.
- Sab ko set mein daalo: "x + 1 hai?" O(1).
- Ginti sirf wahan se jahan `x − 1` set mein NAHI hai.
## Pattern pehchano
Unsorted mein consecutive values → set + run ki shuruaat se expand.
## Best approach
O(n), har number max do baar dekha jaata hai.
## Galtiyan
Har number se expand karna (O(n²) ho jaata hai).

### valid-palindrome
title: Valid Palindrome
lc: 125 valid-palindrome
diff: Easy
pattern: Two pointers (skip non-alphanumeric)
problem: After lowercasing and removing every non-letter/non-digit character, does the string read the same both ways?
example: "A man, a plan, a canal: Panama" → True;   "race a car" → False
analogy: Two proof-readers start at opposite ends of a sentence, skip commas and spaces, and compare letters as they walk towards each other.
hints:
- Easy: build a cleaned string, compare with its reverse (extra space).
- Two pointers on the original string: l from the left, r from the right.
- Skip characters that aren't letters/digits, then compare lowercase versions.
brute: `t = "".join(ch.lower() for ch in s if ch.isalnum()); return t == t[::-1]`.
brutecx: O(n) time · O(n) space
signal: Palindrome + noise → **two pointers that skip**.
optimal:
- l, r = 0, n − 1; while l < r: skip junk on both sides; compare; move.
cx: O(n) time · O(1) space
code:
def is_palindrome(s):

        self.vals = []
        self.mins = []

    def push(self, x):
        self.vals.append(x)
        self.mins.append(min(x, self.mins[-1]) if self.mins else x)

    def pop(self):
        self.vals.pop()
        self.mins.pop()

    def top(self):

    st = []
    for t in tokens:
        if t in ("+", "-", "*", "/"):
            b = st.pop()
            a = st.pop()
            if t == "+":
                st.append(a + b)
            elif t == "-":
                st.append(a - b)
            elif t == "*":
                st.append(a * b)

diff: Medium
pattern: Sort by position + stack of arrival times
problem: Cars drive to target on a one-lane road. A faster car that catches up joins the slower car ahead as one fleet. How many fleets arrive?
example: target 12, position [10, 8, 0, 5, 3], speed [2, 4, 1, 1, 3] → 3
analogy: A single-lane mountain road: a fast car behind a slow truck can't overtake, so it arrives together with the truck. Count the groups by looking at cars from the front.
hints:
- Only the order matters: sort by position, closest to the target first.
- Each car's solo arrival time = (target − pos) / speed.
- From front to back: a car whose time ≤ the fleet ahead's time catches up (merges).
- A slower car (bigger time) becomes a new fleet.
brute: Simulate time step by step.
brutecx: much slower, fiddly
signal: Things moving one way and merging → **sort by position, compare arrival times**.
optimal:
- cars = sorted(zip(position, speed), reverse=True).
- fleets = []; for pos, sp: t = (target − pos) / sp; if not fleets or t > fleets[-1]: fleets.append(t).
- Return len(fleets).
cx: O(n log n) time · O(n) space
code:
def car_fleet(target, position, speed):
    fleets = []
    for pos, sp in sorted(zip(position, speed), reverse=True):
        t = (target - pos) / sp
        if not fleets or t > fleets[-1]:
            fleets.append(t)
    return len(fleets)
test:
check(car_fleet(12, [10, 8, 0, 5, 3], [2, 4, 1, 1, 3]), 3)
check(car_fleet(10, [3], [3]), 1)
check(car_fleet(100, [0, 2, 4], [4, 2, 1]), 1)
trace:
car (pos) | time | fleet ahead | result
10 | 1.0 | — | new fleet
8 | 1.0 | 1.0 | merges
5 | 7.0 | 1.0 | new fleet
3 | 3.0 | 7.0 | merges
0 | 12.0 | 7.0 | new fleet → 3
mistakes:
- Processing from the back of the road.
- Using `//` for the time (times are fractions).
hinglish:
## Sawaal
Ek lane wali sadak pe gaadiyan target tak jaati hain; tez gaadi aage wali dheemi gaadi ko pakad le toh dono ek fleet ban jaati hain. Kitni fleets pahunchengi?
## Analogy
Pahaadi ek-lane sadak: dheemi truck ke peeche tez gaadi overtake nahi kar sakti, truck ke saath hi pahunchti hai. Aage se gaadiyan dekh ke groups gino.
## Kaise sochein
- Sirf order matter karta hai: position se sort, target ke sabse paas wali pehle.
- Har gaadi ka akele pahunchne ka time = (target − pos) / speed.
- Aage se peeche: time ≤ aage wali fleet ka time → merge. Zyada time → nayi fleet.
## Pattern pehchano
Ek direction mein chalte merge hone wale objects → position se sort, arrival time compare.
## Best approach
O(n log n).

### largest-rectangle-in-histogram
title: Largest Rectangle in Histogram
lc: 84 largest-rectangle-in-histogram
diff: Hard
pattern: Monotonic stack (how far each bar extends)
problem: Bars of width 1 have the given heights. Return the area of the largest rectangle inside the histogram.
example: [2, 1, 5, 6, 2, 3] → 10
analogy: Each bar is a building. A banner of that building's height can stretch sideways over neighbours until it hits a shorter building on each side. The best banner is the answer.
hints:
- For each bar as the height: how far can it stretch? Until a shorter bar on each side.
- Brute force finds those limits by scanning: O(n²).
- Keep a stack of bars with increasing heights. When a shorter bar arrives, taller bars on the stack can't extend past it: pop them and compute their areas.
- A popped bar's left limit is the bar now on top of the stack.
brute: For each bar, expand left and right while bars are ≥ its height.
brutecx: O(n²)
signal: "For each element, how far until something smaller?" → **monotonic increasing stack**.
optimal:
- For i in 0..n (treat i == n as height 0): while stack and h[stack[-1]] ≥ cur: height = h[pop]; left = stack[-1] if stack else −1; best = max(best, height × (i − left − 1)). Push i.
cx: O(n) time · O(n) space
code:
def largest_rectangle_area(h):
    stack, best = [], 0
    for i in range(len(h) + 1):
        cur = h[i] if i < len(h) else 0
        while stack and h[stack[-1]] >= cur:
            height = h[stack.pop()]
            left = stack[-1] if stack else -1
            best = max(best, height * (i - left - 1))
        stack.append(i)
    return best
test:
check(largest_rectangle_area([2, 1, 5, 6, 2, 3]), 10)
check(largest_rectangle_area([2, 4]), 4)
check(largest_rectangle_area([1]), 1)
trace:
i (h) | popped (height × width) | stack (heights)
0 (2) | — | [2]
1 (1) | 2 × 1 = 2 | [1]
2 (5) | — | [1, 5]
3 (6) | — | [1, 5, 6]
4 (2) | 6 × 1 = 6, 5 × 2 = 10 | [1, 2]
5 (3) | — | [1, 2, 3]
6 (end) | 3 × 1, 2 × 4 = 8, 1 × 6 = 6 | []
mistakes:
- Forgetting the final flush (the i == n step with height 0).
hinglish:
## Sawaal
Histogram ke andar sabse bade rectangle ka area.
## Analogy
Har bar ek building hai. Us building ki height ka banner side mein padosiyon ke upar tab tak khinch sakta hai jab tak dono taraf koi chhoti building na aa jaaye. Sabse bada banner hi answer hai.
## Kaise sochein
- Har bar ko height maano: kitna phail sakta hai? Dono taraf chhoti bar tak.
- Scan karke dhoondhna O(n²).
- Increasing heights ka stack: chhoti bar aayi → stack ki lambi bars ab aage nahi badh sakti → pop karke area nikalo. Left limit = stack ka naya top.
## Pattern pehchano
"Har element ke liye kitni door tak koi chhota nahi" → monotonic increasing stack.
## Best approach
O(n).
## Galtiyan
End mein height 0 wala flush bhoolna.
